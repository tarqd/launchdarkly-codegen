# .NET prototype

Hand-written sample of the `dotnet` target's output (`Flags.g.cs`) for four
flags: boolean, string, deprecated double number, JSON. `Consumer.cs` calls
every generated member. Both projects pin `LaunchDarkly.ServerSdk` 8.17.2 and
build with `TreatWarningsAsErrors`, `AnalysisLevel=latest-all`,
`AnalysisMode=All`, `EnforceCodeStyleInBuild`, `GenerateDocumentationFile`
and `WarningLevel=9999`:

- `modern/`: net8.0, `LangVersion=latest`, `Nullable=enable`.
- `legacy/`: netstandard2.0, `LangVersion=7.3` (the default for the SDK's
  netstandard2.0 and net462 targets).

    cd modern && dotnet build && dotnet format --verify-no-changes --include-generated

Results (dotnet SDK 8.0.425, 2026-10-10): both build with zero warnings and
the formatter leaves the file unchanged. With the `<auto-generated>` header
removed, so every analyzer applies, the build is still clean once the
namespace doesn't end in the class name (CA1724). Removing the consumer's
`#pragma` makes each deprecated member a CS0618 error, as intended; the
obsolete constant referenced from the obsolete methods doesn't warn.
