# launchdarkly-codegen

A generator that reads flag definitions from the LaunchDarkly REST API and
emits a type-safe wrapper around the official LaunchDarkly SDK for several
languages. See `DESIGN.md` for the design and open questions.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`tarqd/launchdarkly-codegen`), operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
